## ⚙️ How It Works

ragcraft uses a method called Retrieval-Augmented Generation (RAG). Here is a simple explanation:

1. **Retrieval:** The software searches a collection of documents or data to find relevant pieces based on your query.
2. **Generation:** It uses a large language model to interpret the retrieved information and create useful output.
3. **Evaluation:** ragcraft then measures how good the retrieval and generated answers are using built-in tests.

All these steps run inside the app with no need to install or configure extra programs.
